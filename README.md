### Kelvin Ogodo (Identris Systems Limited)

I lead Identris Systems Limited, a Nigerian technology company delivering government biometric enrollment and smart onboarding systems. I also write the code myself, not just the roadmap. Fullstack developer since 2020, working mainly in React and Node.js with Postgres and Supabase behind them.

## What I've built

**Ebonyi State Smart Onboarding Project.** A government biometric enrollment system for the Ebonyi State Local Government Service Commission, covering 13 Local Government Areas. Fingerprint and photo capture in the field using SecuGen scanners and Logitech cameras, running over Starlink where fixed connectivity isn't reliable. Built on React and Node.js, with Supabase and Cloudinary handling backend services and media storage, and a backup strategy around pg_dump automation, point in time recovery, and row level security. Also built the Commission's official public website. Client work, so the source stays private, but the system is live and in daily government use.


**CKB Hash Lock Tutorial.** My first hands on prototype in Nervos CKB development, the starting point for a move into web3 after five plus years in web2. No blockchain background going in, learning by building.
