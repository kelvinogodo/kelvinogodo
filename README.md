### Kelvin Ogodo (Identris Systems Limited)

I lead Identris Systems Limited, a Nigerian technology company delivering government biometric enrollment and smart onboarding systems. I also write the code myself, not just the roadmap. Fullstack developer since 2020, working across React, Next.js and Node on the frontend and API layer, Postgres, Supabase and MongoDB for data, and increasingly Python for automation and trading systems.

## What I've built

**Ebonyi State Smart Onboarding Project.** Government biometric enrollment system for the Ebonyi State Local Government Service Commission, covering 13 Local Government Areas. Fingerprint and photo capture in the field using SecuGen scanners and Logitech cameras, running over Starlink where fixed connectivity isn't reliable. Built on React and Node.js, with Supabase and Cloudinary handling backend services and media storage, and a backup strategy around pg_dump automation, point in time recovery and row level security. Client work, so the source stays private, but the system is live and in daily government use.

**ESLGSC Commission Portal.** The Commission's public facing site plus a role based admin dashboard for four admins, sharing its database with the Smart Onboarding project. Each admin's access is scoped to what they actually need; only the media admin can write to the blog and news tables, everyone else reads employee records without touching them.

**Deriv MT5 Trading Bot.** An automated trading bot for Deriv synthetic indices, built in Python against the MetaTrader5 package. It runs a multi timeframe smart money strategy: identifies trend on the 4 hour chart, marks the order block ahead of the impulsive move, then drops to the 15 minute chart for a fair value gap entry, with strict position sizing and a minimum 1 to 3 risk to reward. Tested on demo before going near a live account.

**CKB Hash Lock Tutorial.** My first hands on prototype in Nervos CKB development, the starting point for a move into web3 after five plus years in web2. No blockchain background going in, learning by building.
